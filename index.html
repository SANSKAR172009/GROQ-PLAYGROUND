From Raw Characters to Intelligent Generation

Welcome to the LLM Pipeline Explorer. Modern Large Language Models (like GPT-4, Llama 3, and Claude) do not process words like humans do. Text undergoes a multi-stage transformation: tokenization, discrete integer mapping, multi-dimensional geometric embeddings, positional phase addition, multi-head causal self-attention, non-linear feedforward networks, and probability distribution sampling.

One-Hot vs Dense Representation Sparsity Problem

If we represented token ID 48 as a one-hot vector across a 32,000-word vocabulary, it would be a vector of 31,999 zeros and one '1'. This is computationally inefficient and lacks semantic similarity.

Continuous Vector Space (Embedding Lookup Matrix WE)
Dimensions (dmodel):

Each token ID indexes a unique row in the embedding matrix WE ∈ ℝ|V| × dmodel. Tokens with similar linguistic and syntactic meanings cluster together in this continuous geometric space.

Why Word Order Matters (Permutation Invariance) The Bag-of-Words Dilemma

Self-Attention is fundamentally a set operation: computing attention between tokens without positions yields the exact same representation regardless of word order! "Dog bites man" and "Man bites dog" would produce identical representations without Positional Encoding.

Sinusoidal Positional Waves (Vaswani et al., 2017)
PE(pos, 2i) = sin(pos / 100002i/d), PE(pos, 2i+1) = cos(pos / 100002i/d)
Element-Wise Addition: Embedding ⊕ Positional Vector X = W_E + PE

Multi-Head Causal Self-Attention
Attention Head:

In self-attention, each token produces a Query (what it seeks), a Key (what it advertises), and a Value (the actual information). Dot products of Queries and Keys determine routing weights.
